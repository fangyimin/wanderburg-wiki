What is Wanderburg?

Wanderburg is a minimalist open-world survivors-like roguelike where you pilot a roaming fortress. Castles hunt, villages flee, and only the biggest stronghold survives.

Each run you consume settlements and rival fortresses to grow, then mount cannons, wizard towers, mines and more. Between runs you unlock modules, vehicles, artifacts and captains for new build paths.
